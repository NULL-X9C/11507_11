## Задание 1. Универсальный валидатор (Generics + Delegates)

Реализуйте класс `Validator<T>`, который проверяет данные на соответствие заданному правилу.

```csharp
public class Validator<T>
{
    public Predicate<T> Rule { get; set; }

    public bool IsValid(T value)
    {
        // Выполнить проверку и вернуть результат
    }
}
```

### Требования:

1. Свойство `Rule` — это делегат, определяющий логику проверки.
2. Метод `IsValid` применяет это правило к переданному значению.
3. Добавьте в класс свойство `ErrorMessage` (string) и метод `EnsureValid(T value)`, который выбрасывает `ValidationException` с заданным сообщением, если проверка не пройдена.

В Main:
1. Создайте `Validator<int>` для проверки, что число положительное.
2. Создайте `Validator<string>` для проверки, что строка не пустая и её длина > 5 символов.
3. Проверьте несколько значений и выведите результат (или поймайте исключение).

## Задание 2. Обратный отсчет (Events)

Реализуйте класс таймера с обратным отсчетом.

```csharp
public class TimerEventArgs : EventArgs
{
    public int SecondsRemaining { get; set; }
}

public class  
{
    private int _seconds;
    public event EventHandler<TimerEventArgs> Tick;
    public event EventHandler Stopped;

    public void Start(int seconds) { ... }
}
```

### Требования:

1. Метод `Start` запускает цикл (можно использовать `Thread.Sleep(1000)` и цикл `for`).
2. Каждую секунду вызывается событие `Tick`, в которое передается оставшееся время.
3. Когда время заканчивается (доходит до 0), вызывается событие `Stopped`.

В Main:
1. Создайте таймер на 5 секунд.
2. Подпишитесь на оба события.
3. В обработчике `Tick` выводите: "Осталось: [N] сек.".
4. В обработчике `Stopped` выводите: "Время вышло! Бум!".

## Задание 3. Обработка XML-данных (IO + LINQ)

Дан файл `orders.xml` следующей структуры:
```xml
<Orders>
    <Order Id="1" Status="Paid" Amount="1500" />
    <Order Id="2" Status="Pending" Amount="500" />
    <Order Id="3" Status="Paid" Amount="3000" />
</Orders>
```

### Требования:

1. Прочитать данные из файла. Обязательно используйте метод `XDocument.Load()` из библиотеки `System.Xml.Linq`.
2. С помощью LINQ:
    - Выбрать все заказы со статусом "Paid".
    - Вычислить суммарную стоимость (Amount) этих заказов.
    - Выбрать ID этих заказов.
3. Сохранить результат в текстовый файл `report.txt` в формате:
   ```text
   Paid Orders: 1, 3
   Total Amount: 4500
   ```
